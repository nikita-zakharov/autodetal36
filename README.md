# autodetal36

Сайт-визитка по подбору автозапчастей в Воронеже. Статический сайт на Astro без Vue и React.

## Локальная разработка

Для установленного Astro 7.4.3 требуется Node.js 22.23.4+ и npm 9.6.5+.

```sh
npm ci
npm run dev
```

## Структура проекта

- `src/pages/index.astro` — главная страница, составленная из секций.
- `src/layouts/BaseLayout.astro` — HTML-документ, SEO, общие стили и Метрика.
- `src/components/` — повторяемые элементы: логотип, кнопки связи, заголовки, карточки и диалог фотографии.
- `src/components/sections/` — секции главной страницы.
- `src/data/site.ts` — контакты, адрес, ссылки карты и маршрута, SEO и идентификатор Метрики. Телефон и MAX изменяются здесь сразу для всей страницы.
- `src/data/content.ts` — марки автомобилей, категории запчастей, преимущества и шаги заказа.
- `src/scripts/` — браузерные скрипты Метрики и диалога фотографии.
- `src/styles/global.css` — оформление, адаптивность и анимации.
- `public/assets/` — изображения, логотипы и иконки; остальные файлы `public/` копируются в корень сборки.

Astro создаёт готовый HTML при сборке. Клиентские скрипты нужны только для Метрики и просмотра фотографии. Стили и скрипты хранятся отдельно от шаблонов.

## Сборка для публикации

```sh
npm run build
```

Готовый сайт находится в `dist/`. Опубликуйте содержимое этой папки на статическом хостинге.
Для локальной проверки сборки выполните `npm run preview`.
