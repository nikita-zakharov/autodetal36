# Инструкции для работы с АвтоДеталь36

## Проект
Русскоязычный сайт-визитка по подбору автозапчастей в Воронеже.
Основная цель — обращения по телефону и в MAX.

Стек: Astro, статическая сборка без Vue и React.
- src/pages/index.astro — композиция главной страницы.
- src/layouts/BaseLayout.astro — HTML-документ и SEO.
- src/components/ — переиспользуемые элементы и секции страницы.
- src/data/site.ts — контакты, адрес, SEO и настройки Метрики.
- src/data/content.ts — данные повторяемых карточек.
- src/styles/global.css — оформление и адаптивность.
- src/scripts/ — браузерные скрипты.
- public/assets/ — изображения, логотипы и иконки.
- public/ — файлы, копируемые в корень сборки.
- dist/ — результат сборки; не редактировать вручную.

## Подход к изменениям
- Сохраняй текущую архитектуру. Добавляй JavaScript и зависимости,
  только когда задача действительно требует их.
- Ограничивай изменения поставленной задачей.
- Используй существующие CSS-переменные и компоненты:
  .wrap, .btn, .section, .tile.
- Сохраняй текущую палитру, типографику и стиль,
  если задача не предполагает их изменение.
- Переиспользуй имеющиеся изображения и SVG.
- Не изменяй посторонние пользовательские файлы.

## Тексты и данные
- Пиши тексты интерфейса и пояснения пользователю по-русски.
- Сохраняй телефон, ссылку MAX, адрес, координаты карты
  и реквизиты, если задача не требует их изменения.
- При изменении контактов проверяй все повторения на странице,
  включая href, title и подписи.
- Не придумывай цены, сроки поставки, гарантии, отзывы
  и сведения о наличии. Наличие и цену уточняют у поставщиков.
- Согласовывай изменения SEO-текстов с видимым содержимым:
  title, description, Open Graph и Twitter metadata.

## Вёрстка и доступность
- Сохраняй семантическую разметку и логичную иерархию заголовков.
- Используй ссылки для переходов, кнопки для действий.
- Сохраняй видимый фокус клавиатуры, skip-link
  и поддержку prefers-reduced-motion.
- Для содержательных изображений указывай подходящий alt,
  для декоративных — пустой alt.
- Проверяй якоря и пути к изображениям с учётом регистра имён.

## Проверка
- После изменений сайта выполняй npm run build.
- Для визуальных изменений проверяй страницу в браузере
  при ширине 360, 768 и 1280 px, если браузер доступен.
- Проверяй отсутствие горизонтальной прокрутки,
  читаемость текстов и доступность основных контактов на мобильных.
- Проверяй ссылки телефона, MAX и маршрута при их изменении.
- Автоматических тестов и линтера сейчас нет.
  Успешная сборка не заменяет визуальную проверку.
- Если проверка недоступна, явно сообщи об этом.
